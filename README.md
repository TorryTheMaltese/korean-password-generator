# 🔐 Korean Password Generator

> **한글로 기억하고, 영문으로 입력하는 비밀번호 생성기**

한글 문구를 기반으로 사람이 기억하고 입력하기 쉬우면서도  
영문 대문자·소문자·숫자·특수문자를 조합할 수 있는 비밀번호 생성 프로그램

한글 문자열을 기억한 뒤 한글 입력 상태에서 그대로 입력하면  
두벌식 키보드의 대응되는 영문 키 배열이 실제 비밀번호로 입력되는 방식을 사용함

Python 기반 핵심 생성 로직, GUI 및 Windows 실행 파일 패키징 구현 완료

---

## 💡 프로젝트 소개

복잡한 비밀번호를 직접 만들다 보면 비슷한 단어나 숫자를 반복해서 사용하거나,  
연도·월·순번 등 일정한 규칙을 적용해 다음 비밀번호를 쉽게 추측할 수 있게 되는 문제가 생길 수 있음

**한글과 두벌식 키보드**를 이용하여 이러한 문제를 줄이면서도  
사람이 비교적 쉽게 기억하고 직접 입력할 수 있는 문자열을 생성하는 것이 목적임

사용자는 한글 형태의 문자열을 기억하고,  
실제로는 **한글 입력 상태에서 해당 문자열을 그대로 입력**하여 대응되는 영문 키 배열을 비밀번호로 사용함

예시

```text
기억할 문자열 : 까마득34##
실제 키 입력  : Rkakemr34##
```

GUI에서는 기억할 한글 문자열만 표시하며,  
실제 두벌식 영문 키 입력값은 내부 검증에만 사용함

## ✨ 주요 기능

- 📄 로컬 텍스트 파일에서 원본 문구 불러오기

- ✨ 특수문자 포함 여부, 최소·최대 개수 및 허용 문자 설정
- 🔐 실제 영문 키 입력값 기준 비밀번호 복잡도 검증
- 🚫 조건을 만족하는 문자열이 없는 경우 오류 처리
- 🖥️ `ttkbootstrap` 기반 GUI 제공
- 📂 원본 문구 파일 직접 선택
- 💾 마지막으로 사용한 원본 문구 파일 경로 기억
- 📋 생성된 기억용 문자열 수동 복사
- 🧪 핵심 생성 로직 단위 테스트
- 📦 PyInstaller 기반 Windows 실행 파일 패키징

비밀번호 생성에 영향을 주는 무작위 요소는 Python의 `secrets` 모듈을 이용해 결정함

## ⇧ Shift 입력 변형

두벌식 키보드에서 `Shift` 입력이 필요한 한글 자모는 아래와 같음

```text
자음 : ㄲ ㄸ ㅃ ㅆ ㅉ
모음 : ㅒ ㅖ
```

추출된 문자열에 위 자모가 이미 포함되어 있으면 그대로 사용 가능함

포함되어 있지 않은 경우 아래와 같이 변형 가능함

```text
ㄱ → ㄲ
ㄷ → ㄸ
ㅂ → ㅃ
ㅅ → ㅆ
ㅈ → ㅉ

ㅐ → ㅒ
ㅔ → ㅖ
```

초성과 중성이 모두 변형 가능한 경우 각각의 변형과 동시 변형을 모두 후보에 포함함

예시

```text
배
├─ 빼 → Qo
├─ 뱨 → qO
└─ 뺴 → QO
```

맞춤법상 자연스러운 한글을 만드는 것이 목적이 아니라  
두벌식 키보드 입력 시 영문 대문자를 포함시키는 것이 목적임

GUI에서 **영문 대문자 포함** 옵션을 해제하면 해당 조건을 적용하지 않을 수 있음

## 🧪 생성 예시

> 동작 방식을 설명하기 위한 가상의 예시임

```text

✓ 최소 길이
✓ 영문 대문자
✓ 영문 소문자
✓ 숫자

```

클립보드 자동 복사는 수행하지 않음

## 💾 마지막 원본 문구 파일 기억

사용자가 GUI에서 원본 문구 파일을 선택하면  
해당 파일의 **경로만** 사용자별 설정 파일에 저장함

다음 실행 시 저장된 파일이 존재하면 해당 경로를 자동으로 불러옴

저장된 파일이 삭제되거나 이동된 경우  
프로그램 위치의 기본 `phrases.txt` 경로를 사용함

Windows에서는 설정 파일을 다음 위치에 저장함

```text
%APPDATA%\KoreanPasswordGenerator\settings.json
```

설정 파일에는 마지막으로 사용한 원본 문구 파일의 경로만 기록함

다음 정보는 설정 파일에 저장하지 않음

```text
원본 문구 내용
생성된 기억용 문자열
실제 두벌식 영문 키 입력값
이전에 생성한 비밀번호 목록
```

## 🔒 보안 설계

### `random` 대신 `secrets`

비밀번호 생성 과정의 무작위 선택에는 Python의 일반적인 `random` 모듈이 아닌  
암호학적으로 안전한 난수 생성을 위한 **`secrets` 모듈**을 사용함

문구 선택, 문자열 위치, Shift 변형, 숫자, 특수문자 등  
비밀번호 생성에 영향을 주는 무작위 요소는 `secrets`를 이용해 결정함

### 예측 가능한 규칙 사용하지 않기

다음과 같이 다음 비밀번호를 추측할 수 있는 단순한 규칙은 사용하지 않음

```text
password11!
password22!
password33!
password44!
```

연도, 월, 분기, 순번 등의 값만 변경하여 새로운 비밀번호를 만드는 방식도 지양함

각 생성 결과는 이전 생성 결과와 관계없이 독립적으로 생성하는 것을 목표로 함

### 원본 문구와 소스코드 분리

실제 비밀번호 생성에 사용하는 원본 문구는 소스코드에 직접 작성하지 않음

기본 원본 문구 파일

```text
phrases.txt
```

사용자가 작성한 `phrases.txt`는 `.gitignore`를 통해 Git 추적 대상에서 제외함

저장소에는 공개 가능한 예시 문구를 작성할 수 있는 아래 파일만 제공함

```text
phrases.example.txt
```

GUI에서는 다른 위치에 저장된 `.txt` 파일을 직접 선택하여 사용할 수도 있음

### 비밀번호 저장 최소화

생성된 문자열과 생성 과정에서 폐기된 후보는  
파일이나 로그에 자동 저장하지 않음

실제 두벌식 영문 키 입력값 역시 GUI에 표시하거나 별도 파일에 저장하지 않고  
내부 검증 용도로만 사용함

생성 결과의 클립보드 복사는 자동으로 수행하지 않으며  
사용자가 **복사** 버튼을 직접 선택한 경우에만 수행함

> 클립보드에 복사된 내용은 운영체제 및 사용 환경에 따라 프로그램 종료 후에도 남아 있을 수 있으므로 주의가 필요함

## 🚀 사용 방법

### 방법 1. Windows 실행 파일 사용

GitHub Releases에서 Windows 실행 파일을 내려받아 실행함

Python 설치 없이 사용할 수 있음

프로그램 실행 후 **파일 찾아보기**를 이용하여  
원본 문구가 저장된 `.txt` 파일을 선택하면 됨

원본 문구는 한 줄에 하나씩 작성함

```text
바람이 부는 날
별빛이 비치는 밤
새로운 길을 걷는다
```

빈 줄은 자동으로 제외함

---

### 방법 2. Python에서 직접 실행

#### 1. 저장소 준비

```bash
git clone https://github.com/TorryTheMaltese/korean-password-generator.git
cd korean-password-generator
```

#### 2. 의존성 설치

```bash
python -m pip install -r requirements.txt
```

#### 3. `phrases.txt` 생성

예시 파일을 복사하여 사용할 수 있음

Windows PowerShell

```powershell
Copy-Item phrases.example.txt phrases.txt
```

Windows CMD

```cmd
copy phrases.example.txt phrases.txt
```

macOS / Linux

```bash
cp phrases.example.txt phrases.txt
```

이후 `phrases.txt`에 사용할 문구를 한 줄에 하나씩 작성함

#### 4. GUI 실행

프로젝트 루트에서 실행함

```bash
python src/gui.py
```

Windows 환경에서 `python` 명령이 등록되어 있지 않은 경우

```powershell
py src/gui.py
```

## 🔐 기본 생성 및 검증 설정

기본 검증 조건

```text
최소 길이      : 8자
영문 대문자    : 1개 이상
영문 소문자    : 1개 이상
숫자           : 1개 이상
특수문자       : 1개 이상
```

기본 생성 설정

```text
한글 문자열    : 3~5글자
영문 대문자    : 포함
숫자           : 포함 / 2~4자리
특수문자       : 포함 / 1~2개
허용 특수문자  : !@#$%^&*
조합 순서      : 한글 + 숫자 + 특수문자
```

일부 생성 조건은 GUI에서 변경할 수 있음

사용하는 시스템마다 비밀번호 정책이 다를 수 있으므로  
실제 적용 전 해당 시스템의 정책을 별도로 확인해야 함

## 📦 Windows 실행 파일 빌드

Windows 실행 파일은 PyInstaller를 이용해 생성함

PyInstaller 설치

```bash
python -m pip install pyinstaller
```

프로젝트 루트에서 빌드

```bash
python -m PyInstaller --noconfirm --clean --onefile --windowed --icon assets/app.ico --name KoreanPasswordGenerator src/gui.py
```

빌드가 완료되면 아래 위치에 실행 파일이 생성됨

```text
dist/
└── KoreanPasswordGenerator.exe
```

`--onefile` 옵션을 사용하므로 배포 시 Python 소스 파일이나 별도의 Python 설치가 필요하지 않음

실제 사용자의 원본 문구 파일은 실행 파일에 포함하지 않음

- 개인적인 원본 문구가 담긴 `phrases.txt`를 공개 저장소에 커밋하지 않아야 함
- 생성된 문자열이나 실제 비밀번호를 평문 파일이나 로그에 불필요하게 저장하지 않는 것을 권장함
- 공유 PC에서는 원본 문구 파일 및 클립보드 사용에 주의해야 함
- 원본 문구 파일의 경로를 기억하는 기능은 편의를 위한 기능이며 파일 자체를 암호화하거나 보호하지 않음

- **Tkinter**
- **ttkbootstrap**
- Python Standard Library
  - `secrets`
  - `pathlib`
  - `dataclasses`
  - `json`
  - `unittest`
- **PyInstaller**
  - Windows 실행 파일 패키징

GUI 스타일링 및 Windows 패키징에 필요한 외부 도구만 추가로 사용함
