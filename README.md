# 🔐 Korean Password Generator

> **한글로 기억하고, 영문으로 입력하는 비밀번호 생성기**

한글 문구를 기반으로 사람이 기억하고 입력하기 쉬우면서도  
영문 대문자·소문자·숫자·특수문자를 포함하는 비밀번호를 생성하는 Python 프로젝트

현재 개발 중 🚧

---

## 💡 프로젝트 소개

복잡한 비밀번호를 직접 만들다 보면 비슷한 단어나 숫자를 반복해서 사용하거나,  
일정한 규칙을 적용해 다음 비밀번호를 쉽게 추측할 수 있게 되는 문제가 생길 수 있음

 **한글과 두벌식 키보드**를 통해 이러한 문제를 줄이면서도 사람이 비교적 쉽게 기억하고 입력할 수 있는 비밀번호를 만들 예정


사용자는 한글 형태의 문구를 기억하지만,  
실제로는 한글 입력 상태에서 해당 문구를 입력할 때 사용되는 **영문 키 배열**을 비밀번호로 사용할 수 있습니다.

문구 일부를 된소리로 변형하여 `Shift` 입력을 유도하고,  
암호학적으로 안전한 난수를 이용해 숫자와 특수문자를 조합할 것

---

## ✨ 주요 기능

개발 예정인 주요 기능

- 📄 로컬 파일에서 비밀번호 생성에 사용할 원본 문구 불러오기
- 🎲 원본 문구에서 짧은 한글 문자열 무작위 추출
- 🔤 일부 한글 초성을 된소리로 변환
- ⌨️ 한글 문자열을 두벌식 영문 키 입력으로 변환
- 🔢 숫자 및 특수문자 무작위 조합
- 🔐 비밀번호 복잡도 자동 검증
- 🔄 조건을 만족하지 않는 경우 자동 재생성
- 🧪 핵심 생성 로직 단위 테스트

## ⚙️ 동작 방식

```text
원본 문구 모음
      │
      ▼
🎲 문구 및 문자열 무작위 선택
      │
      ▼
🔤 일부 글자를 된소리로 변환
      │
      ▼
🔢 숫자 + 특수문자 무작위 조합
      │
      ▼
⌨️ 두벌식 영문 키 입력으로 변환
      │
      ▼
🔐 비밀번호 복잡도 검사
      │
      ├── 조건 미충족 → 다시 생성
      │
      ▼
✅ 최종 비밀번호
```

### 예시

> 동작 방식을 설명하기 위한 가상의 예시

```text
원본 문구    : 바람부는날
문구 변형    : 빠람부는날
추가 문자열  : 42!
기억할 문자열: 빠람부는날42!
실제 비밀번호: Qkfk...42!
```

사용자는 `빠람부는날42!`과 같은 형태로 기억하고,  
실제로는 두벌식 키보드에서 대응되는 영문 키를 입력하는 방식

※ 실제 두벌식 변환 결과는 구현된 변환 로직에 따라 생성됨

## 🔒 보안 설계

### `random` 대신 `secrets`

비밀번호 생성 과정의 무작위 선택에는 Python의 일반적인 `random` 모듈이 아닌  
암호학적으로 안전한 난수 생성을 위한 **`secrets` 모듈**을 사용하는 것을 원칙으로 함

문구 선택, 문자열 위치, 숫자, 특수문자 등 비밀번호 생성에 영향을 주는 무작위 요소는  
가능한 한 `secrets`를 이용해 결정

### 예측 가능한 규칙 사용하지 않기

다음과 같이 다음 비밀번호를 추측할 수 있는 규칙은 사용하지 않음

```text
password11!
password22!
password33!
password44!
```

연도, 월, 분기, 순번 등의 값만 변경하여 새로운 비밀번호를 만드는 방식도 지양

각 비밀번호는 이전에 생성된 비밀번호와 관계없이 **독립적으로 생성**하는 것을 목표로 함

### 원본 문구와 소스코드 분리

실제 비밀번호 생성에 사용하는 원본 문구는 소스코드에 직접 작성하지 않음

```text
phrases.txt
```

와 같은 별도의 로컬 파일에서 불러오도록 구현할 예정이며,  
실제 사용자가 작성한 `phrases.txt`는 Git 저장소에 포함하지 않음

대신 프로그램 사용 예시를 위한 가상의 문구만

```text
phrases.example.txt
```

형태로 제공

### 비밀번호 저장 최소화

생성된 비밀번호와 생성 과정에서 폐기된 후보 비밀번호는  
기본적으로 파일이나 로그에 자동 저장하지 않는 것을 원칙으로 함

## ⚠️ 주의사항

이 프로젝트는 비밀번호 생성을 보조하기 위한 개인 프로젝트입니다.

- 원본 문구 자체를 암호학적인 비밀키로 간주하지 않습니다.
- 생성된 비밀번호의 안전성을 절대적으로 보장하지 않습니다.
- 사용하는 시스템의 비밀번호 정책에 따라 허용 문자 및 최소 길이 등을 별도로 확인해야 합니다.
- 실제 비밀번호나 개인적인 원본 문구를 공개 Git 저장소에 커밋하지 마세요.
- 생성된 비밀번호를 평문 파일이나 로그에 불필요하게 저장하지 않는 것을 권장합니다.
