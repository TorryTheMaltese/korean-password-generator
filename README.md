# 🔐 Korean Password Generator

> **한글로 기억하고, 영문으로 입력하는 비밀번호 생성기**

한글 문구를 기반으로 사람이 기억하고 입력하기 쉬우면서도  
영문 대문자·소문자·숫자·특수문자를 포함하는 비밀번호를 생성하는 Python 프로젝트

현재 핵심 비밀번호 생성 기능 및 단위 테스트 구현 완료  
GUI 및 Windows 실행 파일 배포 기능은 추후 추가 예정 🚧

---

## 💡 프로젝트 소개

복잡한 비밀번호를 직접 만들다 보면 비슷한 단어나 숫자를 반복해서 사용하거나,  
연도·월·순번 등 일정한 규칙을 적용해 다음 비밀번호를 쉽게 추측할 수 있게 되는 문제가 생길 수 있음

**한글과 두벌식 키보드**를 통해 이러한 문제를 줄이면서도  
사람이 비교적 쉽게 기억하고 입력할 수 있는 비밀번호를 생성하는 것이 목적임

사용자는 한글 형태의 문자열을 기억하고,  
실제로는 한글 입력 상태에서 해당 문자열을 그대로 입력하여 대응되는 **영문 키 배열**을 비밀번호로 사용

예시

```text
기억할 문자열 : 까마득34##
실제 키 입력  : Rkakemr34##
```

## ✨ 주요 기능

현재 구현된 주요 기능

- 📄 로컬 파일에서 비밀번호 생성에 사용할 원본 문구 불러오기
- 🎲 원본 문구에서 3~5글자 한글 문자열 무작위 추출
- ⇧ 영문 대문자 생성을 위한 한글 Shift 입력 요소 감지 및 변형
- ⌨️ 한글 문자열을 실제 두벌식 영문 키 입력값으로 변환
- 🔢 숫자 및 특수문자 무작위 조합
- 🔐 실제 영문 키 입력값 기준 비밀번호 복잡도 검증
- 🚫 조건을 만족하는 문자열이 없는 경우 오류 처리
- 🧪 핵심 생성 로직 단위 테스트

비밀번호 생성에 영향을 주는 무작위 요소는 Python의 `secrets` 모듈을 이용해 결정

## ⇧ Shift 입력 변형

두벌식 키보드에서 `Shift` 입력이 필요한 한글 자모는 아래와 같음

```text
자음 : ㄲ ㄸ ㅃ ㅆ ㅉ
모음 : ㅒ ㅖ
```

추출된 문자열에 위 자모가 이미 포함되어 있으면 그대로 사용 가능

포함되어 있지 않은 경우 아래와 같이 변형 가능

```text
ㄱ → ㄲ
ㄷ → ㄸ
ㅂ → ㅃ
ㅅ → ㅆ
ㅈ → ㅉ

ㅐ → ㅒ
ㅔ → ㅖ
```

초성과 중성이 모두 변형 가능한 경우 각각의 변형과 동시 변형을 모두 후보에 포함

예시

```text
배
├─ 빼 → Qo
├─ 뱨 → qO
└─ 뺴 → QO
```

맞춤법상 자연스러운 한글을 만드는 것이 목적이 아니라  
두벌식 키보드 입력 시 영문 대문자를 포함시키는 것이 목적임

```text
✓ 최소 길이

✓ 영문 소문자
✓ 숫자
✓ 특수문자
```

## 🔒 보안 설계

### `random` 대신 `secrets`

비밀번호 생성 과정의 무작위 선택에는 Python의 일반적인 `random` 모듈이 아닌  
암호학적으로 안전한 난수 생성을 위한 **`secrets` 모듈** 사용

문구 선택, 문자열 위치, Shift 변형, 숫자, 특수문자 등  
비밀번호 생성에 영향을 주는 무작위 요소는 가능한 한 `secrets`를 이용해 결정

### 예측 가능한 규칙 사용하지 않기

다음과 같이 다음 비밀번호를 추측할 수 있는 규칙은 사용하지 않음

```text
password11!
password22!
password33!
password44!
```

연도, 월, 분기, 순번 등의 값만 변경하여 새로운 비밀번호를 만드는 방식도 지양

각 비밀번호는 이전 생성 결과와 관계없이 독립적으로 생성하는 것을 목표로 함

### 원본 문구와 소스코드 분리

실제 비밀번호 생성에 사용하는 원본 문구는 소스코드에 직접 작성하지 않음

프로젝트 루트의 아래 파일에서 불러옴

```text
phrases.txt
```

실제 사용자가 작성한 `phrases.txt`는 `.gitignore`를 통해 Git 추적 대상에서 제외

저장소에는 공개 가능한 예시 문구만 포함된 아래 파일 제공

```text
phrases.example.txt
```

### 비밀번호 저장 최소화

생성된 비밀번호와 생성 과정에서 폐기된 후보 비밀번호는  
기본적으로 파일이나 로그에 자동 저장하지 않음

현재 개발 단계에서는 검증을 위해 실제 두벌식 영문 키 입력값을 `[DEBUG]` 형태로 출력 중

향후 GUI 버전에서는 실제 두벌식 입력값은 내부 검증에만 사용하고  
사용자 화면에는 한글 기반 문자열만 표시할 예정

클립보드 자동 복사 기능은 기본 기능으로 제공하지 않을 예정

## 🚀 사용 방법

### 1. 저장소 준비

```bash
git clone https://github.com/TorryTheMaltese/korean-password-generator.git
cd korean-password-generator
```

### 2. `phrases.txt` 생성

예시 파일을 복사해 사용 가능

Windows PowerShell

```powershell
Copy-Item phrases.example.txt phrases.txt
```

macOS / Linux

```bash
cp phrases.example.txt phrases.txt
```

이후 `phrases.txt`에 사용할 문구를 한 줄에 하나씩 작성

```text
바람이 부는 날
별빛이 비치는 밤
새로운 길을 걷는다
```

빈 줄은 자동으로 제외됨

### 3. 실행

프로젝트 루트에서 실행

```bash
python src/main.py
```

Windows 환경에서 `python` 명령이 등록되어 있지 않은 경우

```powershell
py src/main.py
```

### 실행 예시

```text
문구 15개를 불러왔습니다.

🔐 생성 문자열: 이피어쎤15!

[DEBUG] 실제 두벌식 입력: dlvldjTjs15!

[검증 결과]
길이: 12
대문자: True
소문자: True
숫자: True
특수문자: True
결과: PASS
```

`[DEBUG]` 값은 개발 및 검증용으로만 사용 중

## 🧪 테스트

외부 테스트 패키지 없이 Python 표준 라이브러리 `unittest` 사용

프로젝트 루트에서 아래 명령으로 전체 테스트 실행

```bash
python -m unittest discover -s tests -v
```

현재 테스트 범위

- 한글 Shift 입력 요소 판별
- 초성·중성 Shift 변형
- 초성·중성 동시 변형
- 두벌식 영문 키 변환
- 복합 모음 및 겹받침 변환
- 문자열 추출 및 길이 검사
- Shift 조건 후보 필터링
- 비밀번호 복잡도 검증
- 전체 비밀번호 생성 파이프라인

현재 전체 단위 테스트 결과

```text
Ran 24 tests

OK
```

## ⚠️ 주의사항

이 프로젝트는 비밀번호 생성을 보조하기 위한 개인 프로젝트임

- 원본 문구 자체를 암호학적 비밀키로 간주하지 않음
- 생성된 비밀번호의 절대적인 안전성을 보장하지 않음
- 사용하는 시스템의 비밀번호 정책에 따라 허용 문자 및 최소 길이 등을 별도로 확인해야 함
- 실제 운영 비밀번호를 GitHub Issue, README, 소스코드 등에 기록하지 않아야 함
- 개인적인 원본 문구가 담긴 `phrases.txt`를 공개 저장소에 커밋하지 않아야 함
- 생성된 비밀번호를 평문 로그나 파일에 불필요하게 저장하지 않는 것을 권장함
